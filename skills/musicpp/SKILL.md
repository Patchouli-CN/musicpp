# musicpp .music 谱面语言

.music 是一种文本简谱格式，播放器是 `musicpp.exe`（Windows，C++23 编写）。
谱面文件为 UTF-8 编码，CRLF/LF 均可。`#` 开头的行是注释（任意位置均可，包括段落体内）。

## 音高记号

数字简谱，自然大调：**1 2 3 4 5 6 7 = do re mi fa sol la si = C D E F G A B**。

- 不带八度标记时中央八度 = C4~B4（MIDI 60~71），即 `1` = C4 = 中央 C
- `^` 升一个八度，可叠加：`1^` = C5，`1^^` = C6
- `,` 降一个八度，可叠加：`5,` = G3，`1,,` = C3
- `#` 升半音：`1#` = C#4。等音遵循乐理：`3#` = `4`（E#=F），`7#` = `1^`（B#=C）
- `0` = 休止符（占位，不占位则该处无声）
- 八度范围 lvl 0~6（MIDI 21=A0 ~ 108=C8），越界报错
- 记号顺序：数字后紧跟任意组合的 `^` `,` `#`，如 `5#,,` `2#^`

## 时值记号

基本单位 = 一个四分音符。每个记号（音符/休止/和弦）默认时值 1 单位，
记号间以空白分隔，每结算一个记号时间前进其时值。后缀作用于**前一个**音符或和弦：

| 后缀 | 作用 | 例子 |
|------|------|------|
| `-`  | 时值 +1 单位 | `1-` 二分音符（2 单位），`1---` 全音符（4 单位） |
| `_`  | 时值 ÷2 | `1_` 八分，`1__` 十六分 |
| `*`  | 时值 ÷3 | `1*` 三连音的一分子 |
| `%`  | 时值 ÷5 | 五连音 |
| `&`  | 时值 ÷7 | 七连音 |
| `.`  | 时值 ×1.5（附点） | `1_.` 附点八分 |

后缀从左到右复合：`1-_` = (1+1)/2 = 1 单位（四分）。

## 力度记号

默认力度 100（0~127）。两种写法，可与时值后缀复合：

- `>1` —— 重音记号：力度 ×1.25（封顶 127），作用于**后一个**音符/和弦：`>1`、`>[135]`
- `1(80)` —— 精确力度 0~127（0 = 无声），和弦写在括号后：`1(60)`、`[135](100)`

例：`>1(110)_ 2_` = 重音+精确力度+八分。写渐强/渐弱用一串精确力度：`1(60) 2(70) 3(80)`。

## 和弦

`[135]` 或 `{135}`：括号内所有音同时发声，共享一个时值，后缀写在括号后：

```
[135]    大三和弦，1 单位
[35#1#^]_-  和弦，1.5 单位
```

括号不可嵌套，必须闭合。和弦内**不能**有空白（空白会结束当前记号）。

## 小节线与排版

`|` 仅作小节线排版，对发声无任何影响。空行是**声部分组边界**（见下）。

## 双声部

连续的两行音符行（中间无空行、无指令）**同时演奏**：第一行上声部，第二行下声部。
空行、指令行会结束配对。这是手写谱的典型排版：

```
[1#35#1#^]_- [2#4#62#^]_ |     ← 旋律
1#,__ 2#,__ 3,__ 2#,__ |       ← 伴奏（与上行同时）

1 2 3 |                        ← 空行后是新的单声部段落
```

需要两个以上声部时用 `ensemble`（见下）。

## 指令

### speed — 速度

```
speed bpm 120        每分钟 120 个四分音符（范围 1~2000）
speed milisec 500    每个四分音符 500 毫秒（等价 bpm 120）
```

可出现在曲子任意位置实现变速。兼容旧格式：单独一行的裸数字（如 `500`）= `speed milisec 500`。

### wait — 停顿

```
wait 5s        停 5 秒
wait 500ms     停 500 毫秒
wait 1.5m      停 1.5 分钟
wait 1m30s     停 1 分 30 秒（复合字面量）
```

时间值语法：一段或多段 `数字[.数字]单位` 拼接，单位 `ms/s/m/h/d` 必须按从大到小出现（`1h30m15.5s`、`2m100ms` 合法；`30s1m`、`1m30m` 报错）；无单位按毫秒。

### timedelta — 时间常量

```
timedelta intro_gap = 2s
wait intro_gap
speed milisec beat     ← timedelta 也可用于 milisec（毫秒量纲）
```

只能在顶层声明；常量不可重复声明、不可变。

### 段落（定义 + 引用）

```
副歌 {
1 2 3 4 |
5 6 7 1^ |
}

主歌 {
3 3 2 1 |
}

play 主歌
play 副歌
play 副歌      ← 重复段落直接复用
```

- **必须先定义后引用**（前向引用报错）
- 定义本身不出声；`play 名` 或 `play <名>` 均合法
- **移调参数**：`play 名(+N)` / `play 名(-N)`，N = 半音数（±36 以内）。
  半音移调是色彩性的（非自然音阶）；嵌套 play 的参数累加；
  移调后音高越出 MIDI 21~108 报错
- 段落内可用音符行、speed、wait、play（嵌套引用），禁止递归成环
- 段落内定义的段落非法（定义不能嵌套）
- 段落内改 speed / instrument / echo 只影响段内，`play` 返回后自动恢复调用处状态
- 兼容旧写法 `<名> { ... }`

### instrument — 音色

```
instrument 小提琴        中文乐器名（GM 标准音色）
instrument flute       英文 GM 名（大小写/空格不敏感）
instrument 33          裸数字 = GM program 号（0~127）
```

- 作用于**后续写入的声部**；写在段落内即为该段落的音色，合奏时各段落各占独立 MIDI 通道、各用各的音色
- 段落内换音色不影响段外：`play` 返回后自动恢复调用处音色
- 同一声部中途可换音色（产生 program change 事件）
- 未知名称：log warning 并回退标准音色（钢琴，program 0）
- 常用中文名：钢琴/小提琴/中提琴/大提琴/长笛/单簧管/双簧管/萨克斯/小号/长号/圆号/吉他/电吉他/贝斯/竖琴/八音盒/木琴/古筝/尺八/陶笛/太鼓/木鱼 等（完整英文表见 GM 标准 128 音色）
- 每条声部分配独立 MIDI 通道（自动跳过 GM 打击乐通道 10）

### echo — 回音模式

```
echo on      连奏（默认）：音符时值走完不松键，声音自由叠加混响（"回音"效果）
echo off     断奏：时值结束立即发 note-off，音与音干净分明
```

- 可写在中途做分段切换（A 段断奏、B 段回音），批处理与流式播放都按区间生效
- 段落内的 echo 设置不外泄：`play` 返回后恢复调用处状态
- 兼容旧写法：`noteoff on` ≡ `echo off`，`noteoff off` ≡ `echo on`，`#noteoff` ≡ `echo off`
- CLI 全局强制断奏：`musicpp.exe <file> --no-echo`（或 `--noteoff`）

### import — 模块导入

```
import "drums.music"
play drums.鼓点A      ← 被导入文件的段落注册为 模块名.段落名
play drums            ← 被导入文件的主流（段落外的内容）注册为 模块名
```

- 只能用于顶层；路径相对当前谱面文件所在目录
- 自动防重复导入、防循环导入

### ensemble — 合奏

```
ensemble {
play 旋律
play 伴奏
play drums.鼓点A
}
```

- 所有成员从同一时刻起跑，块总时长取最长成员
- 成员**只能是 play 指令**（speed/wait 请在段落内用音符时值表达）
- 按段落名分轨：同一段落名在不同 ensemble 块中复用同一声部

## 写谱工作流

1. 开头定速度：`speed bpm <n>`
2. 重复结构（副歌、鼓点循环）抽成段落，主流只写 `play` 序列
3. 手写双声部谱按"上行旋律 + 下行伴奏 + 空行"排版
4. 验证不发声解析：`musicpp.exe <file.music> --dump`（打印 IR 统计）
5. 调试看解析细节：`musicpp.exe <file.music> --trace`
6. 播放：`musicpp.exe <file.music>`，加 `--no-echo` 可全局断奏

## 常见错误（解析器会带行号报错）

- 先 play 后定义 → "未定义（或尚未解析到）的段落"
- 段落引用成环 → 报出完整调用链 `A → B → A`
- 和弦未闭合 / 括号嵌套
- 非法字符（只允许 `0-7 ^ , # - _ . * % & | [ ] { }` 和空白）
- 八度越界（lvl 0~6）
- ensemble 成员不是 play 指令

## 完整示例

```
# 小星星变奏示例
speed bpm 100
timedelta 段间停顿 = 500ms

主题 {
instrument 八音盒
1 1 5 5 | 6 6 5- |
4 4 3 3 | 2 2 1- |
}

伴奏 {
instrument 弦乐
[1,3,5,]_ [1,3,5,]_ [1,4,6,]_ [1,3,5,]_ |
[1,3,5,]_ [1,4,6,]_ [1,3,5,]_ [1,3,5,]- |
}

ensemble {
play 主题
play 伴奏
}
wait 段间停顿
speed bpm 140
ensemble {
play 主题
play 伴奏
}
```
